# Workline 桌面客户端

work-report 的 macOS 快捷任务客户端。Vue 负责三栏任务界面，Tauri/Rust 负责系统托盘、单实例、开机启动和本机加密凭据。

API Key 加密存放在 `~/Library/Application Support/com.daizl.workreport/`（目录 0700、文件 0600），密钥与机器指纹绑定。不使用 macOS 钥匙串，因此不会弹出系统密码框；代价是保护强度取决于文件权限和全盘加密。

客户端不注册全局快捷键：菜单栏图标左键单击提供「显示主界面」和「退出」，唤起快捷键交给 Manico 等第三方启动器；窗口内使用 `⌘N` 新建任务。

界面约定：

- 任务列表按「逾期 / 今日聚焦 / 接下来 / 未排期 / 最近完成」分组，逾期置顶并用红色标识；高优先级未完成任务标题前带火焰标记
- 详情页左上角状态芯片可直接切换 待办 / 进行中 / 已完成 / 已取消，与网页版共用 `PATCH /work-items/:id/status`
- 快速新建的「初始状态」选「待办」时清空开始与截止日期（显示「待定」），提交后由后端归入待办；「详细内容」是纯文本输入，换行原样保留，需要插图或附件时在网页版补充
- 提醒勾选常驻表单（紧跟日期，不折叠）：「截止日提醒」默认开启；开始日期排到未来时露出「开始日提醒」并默认开启，改回今天或更早即关闭；选「待办」时该区域提示暂不排期。折叠区只保留参与人
- 开始日期与截止日期联动（与网页版一致）：开始日期晚于截止日期时截止日期顺延，截止日期早于开始日期时开始日期提前，不会出现开始晚于截止的区间
- 侧栏「通知」进入消息中心，支持单条已读、全部已读，点击通知直达对应任务；侧栏收起时未读以红点提示

从仓库根目录执行：

```bash
make install-desktop
make dev-desktop
make check-desktop
make build-desktop
```

本地界面开发可运行 `python3 desktop/scripts/mock_api.py`，再运行 `npm --prefix desktop run dev`，使用任意 `wrk_` 开头的测试值绑定 `http://127.0.0.1:8093`。Mock API 仅用于界面开发，不实现真实鉴权。
